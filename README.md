# StudyMate 🌱
App web de estudio para décimo año — Primera prueba III Trimestre 2026.
9 materias (Español, Est. Sociales, Cívica, Biología, Química, Física, Matemáticas, Inglés, Francés)
con resumen, tarjetas (repetición espaciada SM-2), quiz, Feynman, blurting, interleaving, pomodoro,
examen general, buscador, XP, racha y modo oscuro. Contenido basado en el libro Santillana 10°.

## Publicar en GitHub Pages
1. Subí index.html, data.js, app.js y la carpeta assets a tu repo.
2. Settings → Pages → Branch main / root → Save.
3. Queda en https://TUUSUARIO.github.io/NOMBREREPO
